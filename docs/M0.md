# M0 — Recent Uploads and README Reader

Version: **0.1.0**

## Goal

Deliver one dependency-free Mystic Python 3 door that can show recent Aminet
uploads and display a package's README comfortably on a classic 80x25
terminal.

## Acceptance criteria

- [x] Runs as `aminetdoor.mpy`
- [x] Uses `mystic_bbs`
- [x] Python 3 / Mystic `GZ`
- [x] No third-party Python dependencies
- [x] Recent uploads via Aminet's RSS feed
- [x] Numbered selection from the recent-uploads list
- [x] Plain-text README retrieval
- [x] 76-column wrapping
- [x] Paged README reader
- [x] Previous/next navigation
- [x] HTTP timeout
- [x] User-Agent
- [x] Friendly expected-error handling
- [x] Offline helper tests (text cleanup, feed parsing, path derivation)
- [x] Offline network-boundary tests (HTTP/URL/timeout/malformed-feed errors)
- [x] Installation documentation
- [x] License and content-licensing note
- [ ] Verified launch of `aminetdoor.mpy` on a real Mystic BBS installation

## Deferred

Candidates for M1, in roughly the order discussed:

- **Browse**: category tree navigation (`comm`, `demo`, `game`, ...) with
  package counts, mirroring Aminet's own `/tree` structure.
- **Search**: simple keyword search, plus an architecture filter
  (`m68k-amigaos` as the sensible default for a classic-Amiga caller).
- Local README caching, to be a better network citizen on repeat visits.
- A "package of the day" random spotlight, mirroring WikiDoor's Random
  article feature.
- Architecture-aware Recent filtering (only show packages relevant to the
  caller's target platform).
- Screenshot rendering: convert a package's Aminet screenshot into ANSI/CP437
  art via `retropal` for inline display -- no comparable Aminet client does
  this today.
- A local download queue that a sysop-side job can pick up to mirror
  requested packages into the BBS's own file area.

## Why RSS instead of HTML scraping

Aminet's Recent/Browse/Search pages are server-rendered HTML with no JSON
API. HTML layout can change without notice and is fragile to parse with
regular expressions. Aminet does publish a stable RSS feed
(`https://aminet.net/feed`) for new uploads, which M0 parses with Python's
built-in `xml.etree.ElementTree` -- no HTML parser, no third-party
dependency, and a much smaller surface for the door to break on.

Browse and Search (M1) will still need some HTML handling, since Aminet does
not expose those as feeds. That work is scoped separately so M0 can ship
without it.
